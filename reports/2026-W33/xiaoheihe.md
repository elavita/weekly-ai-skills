# 小黑盒文案 2026-W33

## trycompai/crm

Comp AI CRM —— 一个 agentic-first 的开源 CRM，定位就是给 AI agent 用的，不是给人用的。TypeScript 写的，GitHub 8.4k star。思路挺有意思：传统 CRM 都是围绕人类销售流程设计，这个直接倒过来，把 AI agent 当一等公民。如果你在做 agent 相关的应用或者想研究 agent-native 的系统设计，可以 clone 下来看看。#开源 #AI #CRM #Agent

## genspark-ai/genoffice

GenOffice 是 genspark-ai 开源的跨平台 AI 办公套件,基于 Electron + TS,支持 docx/xlsx/pptx/PDF/Markdown 编辑并内置 AI Agent,GitHub 已近 3k Star,适合想白嫖 Microsoft Office 或自建企业办公工具的兄弟。

## Jakubantalik/thinking-orbs

Thinking Orbs - 专为AI/Agent UI设计的点状思考光晕加载动画库，TypeScript开发，9种动画类型+2种尺寸+自动深浅色适配。适合做AI聊天、Agent工具调用等待场景的loading状态展示，集成简单，2.3k stars值得关注。

## QwenAudio/qwen-audio-agent

【开源推荐】QwenAudio/qwen-audio-agent —— AI Agent 的实时语音运行时 🎙️🤖 简单说：让 Agent 能持续语音对话、持续干活、持续在线。 技术看点： • Real-time Voice Runtime，专为 Agent 设计 • 完整覆盖 ASR（语音识别）+ TTS（语音合成） • 兼容 Claude Code / Codex / OpenCode 等 AI 编码工具栈 • 支持 ACP 协议，方便多 Agent 协作 • JS 实现，门槛低，集成快 适用场景：语音编程助手、值守型 Agent、需要「在场感」的语音交互应用。 目前 GitHub 2k+ Star，社区活跃度不错，做 Agent 方向的同学可以重点关注一波 👀 #开源 #AI #VoiceAgent #Agent #开发者工具
