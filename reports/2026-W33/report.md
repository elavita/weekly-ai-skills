## 2. [genspark-ai/genoffice](https://github.com/genspark-ai/genoffice)

![genspark-ai/genoffice](images/genspark-ai-genoffice-fabd671c94.png)

**近 13 天创建** · 2,999 Stars · TypeScript

GenOffice 是由 genspark-ai 开源的免费 AI 办公套件，基于 Electron 与 TypeScript 构建，跨平台支持 macOS、Windows 与 Linux。它集成了 Word (.docx)、Excel (.xlsx)、PowerPoint (.pptx)、PDF 与 Markdown 编辑能力，并内置 AI 代理辅助办公任务。

亮点：
- 完全开源免费的 AI 办公套件,无授权费用
- 跨平台支持 macOS、Windows 与 Linux
- 一站式覆盖 Word、Excel、PowerPoint、PDF 与 Markdown 五大文档格式
- 基于 Electron + TypeScript 构建,易于扩展与定制
- 内置 AI 代理,可辅助文档处理与办公任务
- GitHub 已获近 3000 Star,社区关注度高

适用场景：
- 个人或团队需要零成本替代 Microsoft Office 的日常办公场景
- 跨平台统一办公体验,避免在不同系统间切换软件
- 需要同时处理 Word、Excel、PPT、PDF 与 Markdown 的多格式文档工作流
- 开发者基于开源代码定制企业内部专属办公工具
- 学生与教育场景下的免费文档编辑与作业撰写
- 利用内置 AI 代理辅助撰写、润色或整理文档内容

图片来源：GitHub Open Graph (https://opengraph.githubassets.com/ai-skill-weekly/genspark-ai/genoffice)

## 4. [QwenAudio/qwen-audio-agent](https://github.com/QwenAudio/qwen-audio-agent)

![QwenAudio/qwen-audio-agent](images/QwenAudio-qwen-audio-agent-16d4916d85.png)

**近 18 天创建** · 2,123 Stars · JavaScript

QwenAudio/qwen-audio-agent 是一个面向 AI Agent 的实时语音运行时（Real-time Voice Runtime），让 Agent 能够持续进行语音对话、保持在线工作状态。它基于 JavaScript 实现，聚焦于语音交互链路（语音识别与语音合成），并与多种 Agent 编程工具生态打通。

亮点：
- 实时语音运行时，专为让 AI Agent 持续说话、工作和保持在场而设计
- 覆盖完整的语音交互链路：语音识别（speech-recognition）与文本转语音（text-to-speech）
- 面向 Agent 编程生态，主题涵盖 agent、agentic-ai、voice-agent、voice-ai、voice-chat
- 与主流 AI 编码工具兼容：claude-code、codex、opencode、ai-coding
- 支持 ACP（Agent Communication Protocol）相关能力，便于 Agent 间协作
- 定位为开发者工具（developer-tools），使用 JavaScript 构建
- 社区关注度较高，GitHub Star 超过 2000

适用场景：
- 为 AI 编程 Agent（如 Claude Code、Codex、OpenCode）添加实时语音交互能力，让 Agent 可以边写代码边与开发者对话
- 构建可长时间在线、持续对话的语音 Agent，用于陪伴式或值守类应用
- 在 Agent 工作流中接入语音通道，实现语音输入指令与语音播报结果
- 作为开发者工具，为自定义 Agent 快速集成 ASR + TTS 的实时语音运行时
- 用于需要 Agent 保持“在场感”的场景，例如语音会议助手、实时协作 Agent
- 在多 Agent 协作（ACP）场景中，为 Agent 提供统一的语音交互接口

图片来源：GitHub Open Graph (https://opengraph.githubassets.com/ai-skill-weekly/QwenAudio/qwen-audio-agent)
