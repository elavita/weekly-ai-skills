## yetone/cumora

Cumora 是一个面向 AI Agent 团队的跨平台协作聊天平台，把 AI Agent 作为一等成员接入团队沟通中。它支持云端模型接入，也允许用户自带 Claude Code、Codex 等 Agent 执行环境，方便统一管理不同来源的 Agent。核心亮点包括跨平台使用、Agent 一等公民设计，以及对自带执行环境的开放支持。适用场景包括组建多 Agent 开发或研究团队、在聊天中直接调用编码 Agent 完成代码任务，以及作为多 Agent 协作框架的实验平台。

## CopilotKit/OpenBot

OpenBot（CopilotKit 开源）定位为可治理的 AI 数字员工运行时：每个 Agent 拥有独立浏览器、文件系统和工具环境，行动前审批、行动后记录，兼容 AG-UI 协议与 MCP 工具生态。核心能力包括 Agent 沙箱隔离、审计追溯、生成式 UI 集成与 TypeScript 技术栈。典型用途：企业部署可审计的 AI 员工处理办公自动化、浏览器操作任务，以及作为统一接入层管理多 Agent 系统。
