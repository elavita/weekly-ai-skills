# 小红书文案 2026-W35

本周报汇总近期值得关注的 AI Skill、Agent、MCP 与效率工具，帮助中文开发者快速了解它们的用途并完成初步筛选。内容基于公开仓库信息整理，使用前请自行核验。

## yetone/cumora

Cumora 是一个面向 AI Agent 团队的跨平台协作聊天平台，把 AI Agent 作为一等成员加入团队沟通中。它既支持接入云端模型，也允许用户自带 Claude Code、Codex 等 Agent 执行环境，方便把不同来源的 Agent 统一管理。亮点在于跨平台体验、Agent 一等公民设计，以及对自带执行环境的开放支持。适合需要协调多个 AI Agent 协作的开发者、研究者和团队，也可以作为多 Agent 沟通与分工模式的实验平台。

## CopilotKit/OpenBot

OpenBot 是 CopilotKit 开源的 AI 数字员工平台，给每个 Agent 配一台独立电脑：浏览器、文件、工具全配齐，所有动作执行前要审批、执行后留痕，支持接入任何 AG-UI Agent。亮点在于多 Agent 沙箱隔离、完整审计日志、原生 AG-UI 与 MCP 集成、TypeScript + 生成式 UI 便于前端嵌入。适合需要可治理 AI 员工的企业团队、浏览器自动化场景，以及想快速搭建 Copilot 类产品的开发者。

## Leonxlnx/unlazy

这是一个值得进一步了解的 AI 项目；原始简介：Anti-laziness skill for AI agents. Core: the Depth Tree method, which splits a task N layers deep and gives every leaf the full time budget of the whole task, so effort multiplies with depth. Grounded in 2025-2026 research on model laziness, underthinking and premature completion.
