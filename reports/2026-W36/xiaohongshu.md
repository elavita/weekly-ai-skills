## XiaoDuoYa/codex-with-chatgpt

codex-with-chatgpt 是一个把 ChatGPT 当规划大脑、Codex CLI 当执行终端的桥接项目。它让你在保留 Codex 命令行体验的同时，用 ChatGPT 来拆解任务、生成方案，再交给 Codex 完成实际编码与文件操作。亮点包括：基于 TypeScript 实现，支持 OAuth 复用 ChatGPT 账号，兼容 Model Context Protocol（MCP），可接入外部工具与上下文；整体思路是让模型负责思考、CLI 负责落地，适合喜欢在终端里做 AI 辅助开发的用户。适用场景：在终端用自然语言描述需求并由 ChatGPT 拆解后驱动 Codex 执行；为现有 Codex 工作流补充更强的任务规划与多轮对话能力；作为 MCP 客户端示例，演示 ChatGPT 如何接入支持 MCP 的工具生态；用于个人或小团队验证 ChatGPT + Codex 的协同效果。
